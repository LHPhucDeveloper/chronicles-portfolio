## ✦ About the Project

**Chronicles** is a personal portfolio built around **digital storytelling**. Instead of presenting only a conventional list of skills and projects, it revisits my university years from 2021 to 2025 through a sequence of chapters.

The website brings together early university memories, teamwork, industry experience, software projects, technical exploration, and reflections on personal growth.

> *A record of where the journey began, what I learned along the way, and what I will carry into the next chapter.*

## 🚀 Run Locally

```bash
git clone https://github.com/LHPhucDeveloper/chronicles-portfolio.git
cd chronicles-portfolio
```

Open `index.html` in a modern browser such as Chrome, Edge, or Firefox.

## ☁️ Deployment

The site can be deployed as a static website through [Vercel](https://vercel.com/).

1. Sign in to Vercel with GitHub.
2. Import the `chronicles-portfolio` repository.
3. Keep `index.html` at the repository root.
4. For the current static HTML/CSS/JavaScript setup, no build command is required.
5. Deploy, then test navigation, images, and responsive layouts on desktop and mobile.

> **Live site:** Add your Vercel URL here after deployment.

## ◇ Design Intent

This project is more than a skills checklist. It is a personal record of a formative period: the people who shared the journey, the problems I tried to solve, the technologies I explored, and the lessons that helped shape how I think.

The goal is to tell that story through a visual experience—not just a wall of text.
